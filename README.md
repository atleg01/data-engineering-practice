# COVID-19 Global Case Analysis

A data exploration project analyzing global COVID-19 case data using Python and pandas, with a focus on South Africa's case trends compared to other countries.

## What this notebook does
- Loads and inspects the global COVID-19 dataset
- Converts date columns from text to proper datetime format
- Filters and analyzes case data for South Africa specifically
- Compares confirmed case trends across South Africa, Brazil, and India
- Calculates daily new cases from cumulative totals using `.diff()`
- Visualizes case trends over time with line charts

## Tools used
Python, pandas, matplotlib

## Dataset source
[Novel Corona Virus 2019 Dataset — Kaggle](https://www.kaggle.com/datasets/imdevskp/corona-virus-report)

## Skills practiced
Datetime handling, multi-file dataset navigation, filtering, groupby aggregation, derived columns, data visualization
